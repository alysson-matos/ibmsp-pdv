# IBMemorial - PDV

Eu quero criar um projeto pequeno, que seria como se fosse um ponto de venda, que controle inventário e faça a interface de venda para os usuários. Ou seja, eu teria um guichê com um leitor de códigos de barras e o usuário descreve os produtos que quer comprar e ele vê na tela quais são os produtos, qual o valor final e a forma de pagamento

Não precisa integrar a nenhum metodo de pagamento, apenas quais são as formas.
